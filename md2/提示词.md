你可以把问题设计成：**让 GPT 当老师、按阶段教学、每次只讲一个主题、讲完给代码和练习、最后帮你批改代码**。

## 一、总提示词：让 GPT 成为你的 Linux C 老师

你可以这样问 GPT：

> 我想系统学习 C 语言 Linux 系统编程。
> 请你担任我的老师，按照从入门到进阶的顺序教我以下内容：
>
> 1. Linux 操作系统基础：Shell、常用命令、进程、文件系统、权限、环境变量
> 2. Makefile：gcc 编译流程、Makefile 规则、变量、伪目标、多文件编译
> 3. Linux IO 编程：文件 IO、目录操作、阻塞 IO、非阻塞 IO、select、poll、epoll
> 4. Linux 多进程编程：fork、exec、wait、pipe、signal、进程间通信
> 5. Linux 多线程编程：pthread、互斥锁、条件变量、读写锁、线程同步
> 6. Linux 网络编程：socket、TCP、UDP、并发服务器、epoll 网络模型
>
> 我的基础是：会 C 语言语法，但 Linux 系统编程刚入门。
>
> 教学要求：
>
> * 每次只讲一个主题，不要一次讲太多
> * 每个主题先讲核心概念，再讲常用函数
> * 每个函数都要说明：头文件、函数原型、参数、返回值、错误处理、常见坑
> * 所有代码都用 C 语言，要求能在 Linux 下用 gcc 编译运行
> * 每个例子都要给出编译命令和运行方法
> * 涉及多文件项目时，请给出 Makefile
> * 每节课最后给我练习题
> * 我提交代码后，你要帮我检查 bug、内存泄漏、文件描述符泄漏、并发问题和代码风格
>
> 请先给我完整学习路线，然后从第一课“Linux Shell 基础”开始教我。

## 二、学习 Shell 时这样问

> 请作为 Linux C 编程老师，教我 Linux Shell 基础。
> 我希望掌握以后能熟练编译、运行、调试 C 程序。
>
> 请讲解：
>
> 1. 常用命令：ls、cd、pwd、mkdir、rm、cp、mv、cat、less、grep、find
> 2. 文件权限：chmod、chown、rwx 权限含义
> 3. 输入输出重定向：>、>>、<、2>、2>&1
> 4. 管道：|
> 5. 环境变量：PATH、HOME、LD_LIBRARY_PATH
> 6. 后台运行和进程查看：&、ps、top、kill
>
> 每个知识点都请给例子，并结合 C 程序开发场景说明。

> * 常见使用场景
> * 初学者常见错误

> * 解释线程共享哪些资源，不共享哪些资源
> * 解释竞态条件、死锁、线程安全
> * 先写一个有竞态问题的程序
> * 再用互斥锁修复它
> * 最后写一个生产者消费者模型
> * 给出 Makefile

> 我正在学什么
> 我的当前水平是什么
